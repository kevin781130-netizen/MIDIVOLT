# MIDIVOLT Arrangement Review Engine

The first candidate review engine supports **external AI-generated MIDI proposals** and an optional local chord/bass generator. It does **not** contain a trained AI model or a live DAW plugin.

## Safe process: propose → preview → apply

Start with a melody MIDI `melody.mid`. Track indices are zero based.

### Option A: review an external AI MIDI candidate

```powershell
midivolt-review propose --input melody.mid --candidate candidate.mid --manifest plan.json --lock 0
midivolt-review preview --manifest plan.json
midivolt-review apply --manifest plan.json --out approved.mid --approve
```

`--candidate` may be generated by a model adapter, tsov, or any other MIDI application. The first command rejects candidates that modify locked tracks or global tempo/meter/key maps.

### Option B: use MIDIVOLT's existing deterministic chord/bass generator

```powershell
midivolt-review propose --input melody.mid --chords "Fmaj7 Dm7 Gm7 C7" --candidate-out candidate.mid --manifest plan.json --lock 0
midivolt-review preview --manifest plan.json
midivolt-review apply --manifest plan.json --out approved.mid --approve
```

- Repeat `--lock` to protect additional tracks (`--lock 0 --lock 2`).
- `--no-bass` and `--beats-per-chord` apply only to the built-in chord generator.
- `apply` **must** be given `--approve`; it always creates a new MIDI and will never overwrite the source, candidate, manifest, or an existing output file.
- Proposal JSON records SHA-256 hashes for the original and candidate plus locked tracks and note-level differences. Preview/apply re-read and verify hashes and recompute the diff; editing files after review invalidates approval.
- Locked tracks protect program, drum flag, track name, notes, velocity, timing, control changes and pitch bends. Timing changes and global key/meter/tempo changes are rejected. Track identity is compared at the same MIDI track index.
- Diff counts inserted and removed MIDI notes, and reports metadata/automation edits in unlocked tracks. It is **not** a note-by-note semantic voice-leading score.
- The manifest records absolute local file paths, is not a cryptographic signature, and is not intended for untrusted multi-user shared folders.
- Standard MIDI via pretty_midi does not guarantee preservation of every proprietary SysEx/text/DAW marker. Original bytes remain untouched.

## Testing

`pytest -q tests/test_review_engine.py` (pretty_midi only).

This suite verifies hash invalidation, metadata and melody locks, multi-track candidate diffs, explicit approval and output protection. Native Cubase/VST3, model inference, and quality of musical arrangements remain future acceptance criteria.
