## Product engineering estimate

Before this slice: ~25% of MIDI Agent's user-facing product scope.
After proving the basic text instruction and multitrack MIDI flow:
~28% **subjective feature-parity estimate**. This figure is not a
measured completion statistic and is NOT an estimate of remaining
time or engineering effort. Real LLM providers, editing dialogue,
instrument-aware music quality tests, standalone UI and host plug-in
formats carry the majority of remaining product risk.

The safer next implementation milestone is a model-provider-neutral
structured note-event protocol (bounded schema, no arbitrary code,
prompts + source MIDI context, strict note/music validation), plus
one opt-in real API/local LLM adapter and an explicit fallback label.
Preserve MIDIVOLT's existing review-first and source MIDI lock gates.
